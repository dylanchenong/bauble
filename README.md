# Curio — landing page

Marketing site for **Curio**, an iOS app that blocks distracting apps on a
schedule and unlocks them when you read a short fact and answer one quiz
question about it.

Static HTML/CSS/JS, no build step. Served via GitHub Pages from the root of
`main`. Legal pages (`terms.html`, `privacy.html`) are generated from the
Markdown sources kept in the app's main repository.

To preview locally:

```sh
python3 -m http.server
```
